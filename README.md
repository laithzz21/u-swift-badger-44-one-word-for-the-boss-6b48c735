## The entry

> Hovercraft

The boss who never actually lands — just hovers over your shoulder, humming, watching every keystroke, never quite touching down and never quite going away. One word, instantly visual, and true for anyone who has ever felt a presence behind their chair without hearing a footstep.

## What this does

`main.py` (Python 3, stdlib only, deterministic — no network, clock, or randomness) validates the entry (exactly one word, letters only, no spaces or punctuation, 1–30 characters), prints exactly that word to stdout, and also writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT` when set, falling back to `./output/entry.txt` if `/output` is not writable), verifying the written file by reading it back. A failed file write only warns on stderr — the printed word is the entry, and the run still exits 0.

## How to run

```bash
python3 main.py
```

Exits 0 on success. The entry word is printed to stdout and written to `entry.txt` in the output directory.
